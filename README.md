Lucky Atulya Foundation is dedicated to selfless community service, elderly & widow welfare, emergency ambulance coordination, underprivileged daughter marriage support, medical assistance, and Gau Seva across Jasrana and Firozabad regions.

---

## 🌟 Key Features

- **7 Dedicated Welfare Services:**
  1. Old Age & Widow Pension Assistance (वृद्धा एवं विधवा पेंशन सहायता)
  2. Free Ambulance Service Coordination (निःशुल्क एम्बुलेंस सेवा)
  3. Daughter's Marriage Assistance (कन्या विवाह सहयोग)
  4. Community Social Welfare Initiatives (सामाजिक कार्यों में सहयोग)
  5. Medical Treatment Assistance for Needy (जरूरतमंदों के उपचार हेतु सहयोग)
  6. Religious & Cultural Event Support (विभिन्न धार्मिक कार्यों में सहभागिता)
  7. Gau Seva & Protection (गौ सेवा एवं संरक्षण)
- **Dual Language Support:** Bilingual switch between Hindi (हिंदी) and English via integrated Google Translate widget.
- **Fluid & Accessible Typography:** Optimized using CSS `clamp()` and Noto Sans Devanagari with enhanced line-height for elderly visitors and mobile users.
- **Direct Citizen Action:** One-tap direct dial and WhatsApp messaging for immediate help and volunteer registration.
- **Official Social Media Integration:** Connected to official YouTube, Instagram, and Facebook channels.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Satishkush4446/Lucky_Aturva_Foundation.git

# Navigate to project directory
cd Lucky_Aturva_Foundation

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
